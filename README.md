Streamlit GenAI Chatbot

An AI-powered chatbot built using Python, Streamlit, and Groq API.

Features

- AI-powered conversations
- Interactive Streamlit interface
- Fast responses using Groq LLM
- Easy-to-use chatbot interface

Technologies Used

- Python
- Streamlit
- LangChain
- Groq API

Installation

1. Install dependencies

pip install -r requirements.txt

2. Configure your Groq API key securely using Streamlit secrets.

3. Run the application

streamlit run chatbot.py
